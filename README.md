# Révisions SQL

Ouvre `index.html` dans un navigateur.

Pour apprendre en jouant, choisis **Mini-jeu** : tu gères une boutique en ligne à travers 22 décisions SQL. Chaque étape renvoie à la fiche de cours correspondante et explique la réponse après ton choix.

## Où modifier le contenu

- `js/data.js` : fiches de cours, schémas, questions et liens vers les PDF.
- `js/app.js` : navigation, composition du quiz, correction et progression.
- `css/style.css` : couleurs, mise en page et adaptation aux petits écrans.
- `pdf/` : les trois documents de référence affichés dans la page.

Les fichiers JavaScript restent chargés directement par `index.html` pour que la page puisse aussi s’ouvrir sans serveur local.
